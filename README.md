🎮 游戏背景
生活不仅有诗和远方，还有：
早上 7 点响起的夺命连环闹钟 ⏰
像雪片一样飞来的 DEADLINE 文件 📄
逐渐见底的体力槽（尴尬值） 📉
你的任务？别倒下。 只要我跳得够快，生活的苦难就追不上我！

✨ 核心玩法 (或是“求生指南”)
基础跳跃：按 空格 或 点击屏幕。躲避那些试图终结你美梦的闹钟。
二段跳：在空中再来一下！自嘲熊的潜力是无限的（仅限捡到地鼠时）。
医疗包：收集 咖啡杯 ☕️。这是现代打工人的续命神水，能减少你的“尴尬值”。
神秘队友：撞上 地鼠 Mole 获得二段跳次数。地鼠虽小，关键时刻真能救命。
反复横跳：连续躲避障碍物会触发“求生欲望”，自动回复体力。

🛠️ 技术内幕 (给极客看的)
虽然我看起来很可爱，但我的内心（代码）很硬核：
纯原生 JS 驱动：不依赖任何笨重的引擎，轻量级得像凌晨三点的自嘲熊。
粒子系统：被打到时溅射的不是血，是散落的灵魂碎片 ✨。
音效合成：内置 AudioContext 实时合成音效，连碰撞的声音都透着一丝委屈。
自适应设计：无论是在 4K 显示器还是带裂纹的手持设备上，都能完美展示你的菜。
